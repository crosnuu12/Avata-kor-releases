# 아바타 1.1.2 주문별 매매일지 통합 준비본

설치 프로그램이 아닌 검토·검증용 파일입니다. 실행 중인 아바타 폴더에 덮어쓰지 마세요.

## 반영 내용

- 같은 계좌·종목·날짜·주문번호의 분할 체결을 매매일지 한 행에 합칩니다.
- 수량과 실제 체결금액을 합산하고, 단가는 체결금액 합계 ÷ 수량 합계로 표시합니다.
- 추가 체결은 기존 행에 누적하며, 주문번호를 함께 표시합니다.
- 주문번호가 다르거나 날짜가 다르면 따로 기록합니다.
- 기존 자동 기록도 원장과 대조한 뒤 통합합니다. 수동 기록은 보존합니다.
- 원본 체결은 프로그램 원장에 보존하며, 자산·실현손익은 원래 체결 순서로 계산합니다.
- 기존 1.1.2의 텔레그램 승인과 입력 오류 진단 기능을 포함합니다.

## 현재 검증 상태

수정 기능의 로컬 검사 55개 통과, PowerShell 파일 63개 문법 검사 완료.
첫 Windows 검사에서 테스트용 배열 생성의 PowerShell 5.1 호환성 문제를 발견하여 수정했습니다. 전체 검사를 다시 실행하며 실제 설치·시트 적용은 아직 하지 않았습니다.
기존 준비본의 Windows 475개 검사 결과는 이번 변경의 검증 결과가 아닙니다.
완전한 Windows 검증은 Run-Checks.ps1과 트레이·시작 검사가 수행합니다.

2026-11-04 사용자가 소스 공개로 전환하는 것을 승인했습니다. 인증정보·계좌정보·서명키는 포함하지 않습니다. 현재 실행 중인 프로그램과 시트는 변경하지 않았습니다.
