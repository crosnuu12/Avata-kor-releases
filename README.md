# Avata

Current public release: [Avata 1.1.3 (58.17.9)](https://github.com/crosnuu12/Avata-kor-releases/releases/tag/v1.1.3).

This version adds automatic, sanitized main-PC diagnostic log transmission to the application's configured spreadsheet. See the [release notes](releases/1.1.3/RELEASE_NOTES.md) and [verified release status](releases/1.1.3/STATUS.md).

The signed automatic-update feed is [avata-update.json](https://github.com/crosnuu12/Avata-kor-releases/releases/latest/download/avata-update.json). Existing installations that use confirmation while running can apply it with the in-app update button.
