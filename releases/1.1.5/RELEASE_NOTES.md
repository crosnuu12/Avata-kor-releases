# Avata 1.1.5 / 58.17.11

- 장중 실주문이 실제 활성화되면 “본장에 출근했습니다. 실주문 시작합니다”를 텔레그램으로 보냅니다.
- 장 마감 후 계좌 대조, 매매일지 반영, 장 마감 이후 시작한 자산 내역 조회와 시트 반영이 끝나면 “장 마감으로 일일정산 후 퇴근합니다.”를 보냅니다. 미체결·불명 주문이나 보고서 오류가 남아 있으면 기다립니다. 이는 앱의 일일 집계이며 증권사 결제일 완료를 의미하지 않습니다.
- 두 알림 모두 “메인PC / yyyy-MM-dd HH:mm:ss (KST)”를 표시합니다. 트레이 실행을 미니PC로 오인하던 분기를 제거했습니다.
- 기존 “실주문 시작합니다.” 단독 알림은 제거했습니다. 시작 승인 버튼과 실패 알림은 유지합니다.
- 증권사 시장일정의 개장·폐장 시각을 사용합니다. 휴장일, 조회 실패, 오래된 상태, 모의 운용, 실주문 비활성 상태에서는 출근 알림을 보내지 않습니다.
- 알림 대기열과 하루별 표시를 함께 저장해 재시작·업데이트·반복 조회에 따른 중복을 막습니다. 네트워크 전송 실패는 기존 대기열에서 재시도하며, 지난 장의 출근 알림과 전날 퇴근 알림은 만료시킵니다. 네트워크 응답 유실 시 Telegram 특성상 전달 중복 가능성까지 제거할 수는 없습니다.
- 메인PC 전용 운영으로 전환했습니다. 이전 설치 파일은 archive/minipc-20261105 브랜치에서 복원할 수 있고, 이전 서명 릴리스는 그대로 보존합니다. 공유 계좌 원장·매매일지는 삭제하지 않습니다.

앱이 실행되고 조회가 정상 진행 중이어야 알림을 보낼 수 있습니다. 장 마감 알림은 정산 조회 때문에 마감 시각보다 늦게 도착할 수 있습니다. 거래 설정, 하루 매수 제한, 기준표 지정가 로직은 변경하지 않습니다.

업데이트는 기존 앱의 업데이트 버튼을 사용합니다. 기존 중지·미체결 확인 절차 후 설치되며 자동 시작 설정은 유지됩니다.

검증: Windows PowerShell 5.1에서 668개 합성 검증을 실행하는 CI가 배포를 통제합니다. 새 시장 알림 53개와 트레이 기기 표시 2개 검증이 포함됩니다. 실제 주문·계좌 접근·텔레그램 전송은 시험하지 않습니다. 실제 설치 여부는 메인PC 버전 로그로 확인합니다.
