# Avata 1.1.3 · 메인PC 실시간 진단

시트 연동이 켜진 아바타에서 `메인PC_진단` 탭으로 상태와 최근 로그를 자동 전송합니다. 기존 시트 설정을 사용하며 별도 로그 프로그램을 설치할 필요가 없습니다.

- 정상 연결 시 약 20~30초 간격으로 전송합니다. 인터넷 오류에는 최대 120초 간격으로 재시도합니다.
- 계좌 조회·매매일지 처리와 별도의 작업으로 실행하여 원장 오류가 있어도 진단을 전송합니다.
- 원본 기록 시각과 수집 시각을 구분하고, 앱 원본이 90초 이상 지연되면 `APP_STALE`로 표시합니다.
- 인증키·토큰·계좌번호·잔고·종목 보유내역·주문번호·원문 오류는 전송하지 않습니다. 진단 코드와 횟수, 실행 식별자만 허용합니다.
- 최초 연결 PC의 무작위 장치 ID에 연결되어 다른 PC의 로그가 같은 탭을 덮어쓰지 못합니다.
- 아바타 실행·재시작·업데이트 후 자동 연결됩니다. PC가 꺼져 있거나 아바타 관리자 또는 인터넷이 멈추면 전송도 멈추며 마지막 수집 시각으로 구분합니다.

내부 버전은 `58.17.9`입니다. 기존 주문 전략과 실주문 승인·정지 정책은 유지합니다. 1.1.2에 적용한 업데이트 공개키를 그대로 사용합니다.
