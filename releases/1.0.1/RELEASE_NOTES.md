# Avata 1.0.1 · 내부 빌드 58.17.6

최소화한 아바타를 트레이에서 열어도 화면이 나오지 않던 오류를 수정합니다.
프로그램에 표시되는 내부 빌드는 **58.17.6**입니다.

## 수정 내용

창을 표시하는 과정에서 이전 최소화 상태가 다시 적용되는 문제를 수정했습니다.
복원 중 발생하는 크기 변경 이벤트가 창을 다시 트레이로 숨기지 않게 했습니다.
사용자가 트레이를 더블클릭하거나 **아바타 열기**를 누르면 정상 크기의 창이 표시됩니다.
실행·자동 재시작 시 트레이에 머무르는 동작은 유지합니다.

1.0에 포함된 알림 판정 수정과 기존 자동 시작·날짜 전환·현금 대조 기능을 포함합니다.
자동매매 전략, 주문 제한, 사용자 동의 및 계좌 데이터 처리 조건은 변경하지 않았습니다.

## 적용 방법

기존 버전에서 창이 열리지 않아도 트레이 아이콘 우클릭 → **아바타 종료**를 사용할 수 있습니다.
아이콘이 사라져 정상 종료된 뒤 기존 Avata_kor 실행 도구로 다시 실행하세요.
새 빌드는 트레이에서 시작하며 더블클릭 또는 아바타 열기로 확인합니다.
프로그램 표시가 **58.17.6**인지 확인하세요.

실주문 승인·주문 처리 중에는 업데이트가 보류될 수 있습니다.
자동 실주문 시작은 해당 PC·계좌·종목에 대한 기존 사용자 설정을 따릅니다.
같은 계좌에서 다른 PC가 실주문을 실행 중이면 추가 PC는 조회 용도로 사용하세요.

## 검증

- 기존 Windows PowerShell 5.1 검사 254건.
- 격리된 GitHub Windows 실행 환경의 실제 창·이벤트 검사 10건.
- 최초 복원, 최소화 후 더블클릭, 우클릭 메뉴 열기, 두 경로를 번갈아 10회 반복, 자동 창 표시 차단 확인.
- 기존 버전의 복원 실패를 재현한 후 수정본에 동일 조건을 적용합니다.
- 서명·파일 해시·공개 자동 업데이트 피드 검증을 수행합니다.

실제 미니PC의 원격 입력 결과는 적용 후 확인 대상입니다.
개인정보, 인증정보, 실제 원장·로그 및 서명 개인키는 배포하지 않습니다.
