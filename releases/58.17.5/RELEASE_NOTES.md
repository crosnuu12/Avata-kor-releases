# Avata 공식 1.0 · 내부 빌드 58.17.5

공식 제품 버전은 **1.0**, 프로그램과 자동 업데이트에 표시되는 내부 빌드는 **58.17.5**입니다.

## 수정 내용

- 실전 모드에서 실행하지 않는 모의매매 감시가 5분 후 잘못된 장애 알림을 보내던 문제를 수정했습니다.
- 정상적인 장 시작 대기, 장 마감 대기, 계좌 대조 대기를 장애로 알리지 않습니다.
- 주문 확인 필요 상태, 확인되지 않은 주문, 실제 조회 오류, 수신 연결 장애 알림은 유지합니다.
- 이전 실행에서 남은 실전 상태로 현재 실행의 장애 알림을 만들지 않습니다.
- 기존 트레이 시작·최소화, 사용자가 선택한 자동 실주문 시작, 날짜 전환, 예탁금이용료 대조 수정을 포함합니다.

## 업데이트 방법

기존 Avata_kor 실행 도구를 사용하면 서명된 자동 업데이트 피드에서 이 빌드를 받을 수 있습니다.
기존 프로그램이 실행 중이라면 안전하게 종료한 뒤 다시 실행하세요.
실주문 승인·주문 처리 중에는 자동 업데이트가 보류될 수 있습니다.
업데이트를 위해 실주문을 정지하거나 일시정지한 경우, 자동 시작 설정도 꺼지므로 적용 후 사용자 의도에 맞게 다시 설정해야 합니다.

프로그램은 트레이에서 시작합니다. 오른쪽 아래 숨겨진 아이콘(∧)에서 아바타 아이콘을 두 번 눌러 창을 여세요.
프로그램 표시 **58.17.5**, 정상 계좌 조회 및 업데이트 완료 상태를 확인하세요.

자동 실주문 시작은 PC·계좌·종목별 사용자 선택 사항이며 기본값은 꺼짐입니다.
동일 계좌를 사용하는 다른 PC에서 실주문을 실행 중이라면 추가 PC는 조회 용도로 사용하세요.
배포 및 업데이트가 새 실주문 동의를 만들지는 않습니다.

## 검증

Windows PowerShell 5.1의 격리 환경 검사 **254건**:
기존 검사 209건과 알림 회귀 검사 45건입니다.
두 오경보 재현 조건, 실제 장애 알림 유지, 관리자 호출 경로, 트레이 시작과 조회,
날짜 전환, 현금 대조, 사용자 동의 및 주문 제한 검사를 포함합니다.
서명·해시 확인 후 배포하고, 기존 58.17.0 업데이트 모듈로 공개 피드 호환성을 확인합니다.
실제 장중 주문과 자정 연속 운영 결과는 별도 관찰 대상입니다.

기존 58.17.4 파일을 덮어쓰지 않고 새 빌드로 배포합니다.
개인정보, API 키, 텔레그램 토큰, 시트 주소, 실제 원장·로그, 서명 개인키는 포함하지 않습니다.
