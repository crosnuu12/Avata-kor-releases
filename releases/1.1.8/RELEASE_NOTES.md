# Avata 1.1.8 / 58.17.14

## 변경사항

- 체결 0건·잔량 0건으로 확정된 거부 주문은 미해결 주문으로 오인하지 않습니다.
- `LIVE_ORDER_REJECTED`를 기록·알리고 실주문을 해제해 같은 주문의 자동 재시도를 막습니다.
- 새 계좌 조회 2회 대조, 미체결 0건, 불확실 주문 0건을 만족하면 사용자가 요청한 업데이트를 이어갑니다.
- 부분 체결 거부, 미체결, 조회 불명, 원장 불일치 상태는 기존처럼 확인 전까지 업데이트를 차단합니다.
- 거부 주문을 포함한 진단 이벤트는 허용된 진단 코드만 별도 아카이브로 전송합니다.

## 검증

Windows PowerShell 5.1 회귀검증·트레이·시작 검증 및 공개키 서명·실제 업데이트 다운로드 확인 후 공개합니다. 합성 데이터만 사용하며 실계좌나 주문을 호출하지 않습니다.
