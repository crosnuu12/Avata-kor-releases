# Avata 1.1.10 / 58.17.16

## 거부 주문 확인 후 복구

확정된 주문 거부가 반복될 때마다 새 버전을 설치할 필요 없이, 실전 제어 탭에서 복구할 수 있습니다.

1. 메리츠 앱에서 미체결이 없고 거부 상태가 확정되었는지 확인합니다.
2. 정상 체결된 거래가 시트 매매일지에 반영되었는지 확인합니다.
3. **거부 주문 확인 후 복구**를 누르고 확인 항목을 체크합니다.
4. 프로그램이 새 계좌 조회 두 번과 현재 체결 내역에 일치하는 시트 반영 증거를 대조합니다.
5. **복구 완료 · 실주문 시작 필요** 상태에서 별도로 **실주문 시작**을 누릅니다.

복구 자체로는 주문을 제출·취소하거나 실주문을 시작하지 않습니다. 복구를 요청하면 자동 시작 설정을 끄고, 사용자의 별도 시작을 기다립니다. 확정 거부 이력과 체결 원장은 삭제하지 않습니다.

확인한 거부 기록은 계좌·전략·주문 증거와 함께 암호화해서 보관합니다. 같은 실행이나 나중에 다시 시작할 때 재사용하며, 새 거부·주문 증거 변경·다른 계좌 또는 전략에는 적용하지 않습니다. 조회 불명, 부분 체결 거부, 미체결, 계좌 불일치와 시트 미반영은 계속 차단합니다. 서킷브레이커·사이드카 여부를 문구만으로 추정해서 주문 상태를 바꾸지 않습니다.

## 검증과 적용

실계좌·실주문 없이 반복 거부/복구, 재시작, 장외→개장, 시트 증거 불일치, 오래된 조회, 확인 누락, 정지 경합 및 기존 회귀 검사를 수행합니다. 실제 공개 상태는 STATUS.md와 배포 작업에서 확인합니다.

이번 기능 추가 업데이트를 적용한 뒤에는 같은 종류의 **확정 거부**를 이 버튼으로 복구할 수 있습니다. 확인되지 않은 주문이나 다른 장애를 강제로 해제하는 버튼은 아닙니다.
