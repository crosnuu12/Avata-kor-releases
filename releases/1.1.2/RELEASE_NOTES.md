# Avata 1.1.2 (build 58.17.8)

- 같은 계좌·종목·날짜·주문번호의 분할 체결을 매매일지 한 행으로 통합합니다. 수량과 실제 체결금액을 합산하고 수량가중 평균단가와 주문번호를 표시합니다.
- 추가 체결은 같은 행에 누적합니다. 원본 체결 원장은 보존하며 자산·실현손익 계산은 원래 체결 순서를 유지합니다.
- 기존 자동 기록은 원장과 검증한 뒤 통합하고, 수동 기록은 유지합니다. 변경 전 매매일지를 Windows 사용자 암호화로 백업하며 백업 실패 시 쓰지 않습니다.
- 자동 시작이 꺼져 있고 준비가 완료된 경우 Telegram Yes/No로 한 번의 시작 요청을 승인할 수 있습니다. 기존 주문 승인·계좌 대조·최신성 검사는 유지됩니다.
- 입력 대기 오류를 파일 읽기·암호 해제·파싱·시각·날짜·새로고침 단계별로 구분하는 진단 로그를 추가합니다.

Windows PowerShell 5.1 검사 532개를 통과한 원본을 사용합니다. 실제 인증정보, 계좌 기록, 사용자 설정, 서명 개인키는 배포 파일에 포함하지 않습니다.

자동 업데이트는 기존 앱의 업데이트 설정과 안전한 적용 시점을 따릅니다. 실행 중인 매매를 강제로 중단하거나 원격으로 실주문을 시작하지 않습니다. 이 릴리스는 기존 설치의 업데이트이며 새 PC용 설치 프로그램은 포함하지 않습니다.

매매일지 통합 후 구버전으로 직접 덮어쓰지 마세요. 이전 버전으로 되돌릴 경우 현재 체결 원장을 기준으로 분할 체결 단위의 매매일지를 복원해야 합니다.
