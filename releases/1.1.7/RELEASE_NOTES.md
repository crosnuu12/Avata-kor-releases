# Avata 1.1.7 / 58.17.13

## 변경사항

- 정상 반복 로그는 PC에 순환 보관하고 원격 진단 아카이브에는 장애 이벤트와 전후 제한 문맥만 보냅니다.
- 장애 전 5분과 복구 후 2분의 정상 로그를 해당 장애 이벤트에 문맥으로 연결합니다.
- 오프라인 전송 대기열, 고정 행 ID 재시도, 중복 억제를 추가합니다.
- 진단 필드 허용 목록을 적용하고 계정·잔고·보유내역·토큰·원문 오류 메시지는 원격 전송하지 않습니다.
- API 응답 코드(S607 등)를 보존합니다.

실제 주문 로직과 전략 판단 변경은 포함하지 않습니다.
