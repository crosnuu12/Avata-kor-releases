# Avata 1.1.4 / 58.17.10

매수 기준표의 해당 차수 가격을 지정가 주문에 그대로 사용합니다. 현재가가 여러 차수 기준 아래에서 머물러도, 각 차수 체결 확인 후 다음 차수를 진행합니다. 하루 최대 3개 신규 매수 차수, 자금 및 위험 제한, 한 번에 하나의 활성 주문은 유지됩니다.

- 기준표 계산식과 시장추세 선택은 유지됩니다. 체결 금액으로 이후 차수의 매수 기준을 낮추지 않습니다.
- 실제 체결 가격·수량·금액으로 원장과 매매일지를 갱신합니다. 같은 주문의 분할 체결은 기존처럼 가중평균 체결가와 정확한 합산 금액으로 기록합니다.
- 부분 체결 후 취소된 매수는 최초 차수 목표의 잔여 수량만 재주문합니다.
- 메리츠 현재가 API의 당일 상한가(mxpr)·하한가(llam)를 사용합니다. 기준표 가격이 상한가보다 높으면 주문가격만 상한가로 제한합니다. 실주문 전 한도 누락·오류·범위 초과를 차단하며, 취소 주문은 이 검사로 막지 않습니다.
- 기존 다음 사이클 상승 돌파 진입과 매도 규칙은 유지됩니다.
- 증권사 경고·보류는 정상 접수로 간주하지 않으며 자동으로 경고 확인을 우회하지 않습니다.

메리츠 공개 주문착오방지기준의 주식·ETF·ETN 주문가격 경고/보류 항목은 모두 ‘—’입니다. 임의의 현재가 대비 퍼센트 제한을 만들지 않았습니다. 메리츠는 개별 상황에서 강화된 기준을 적용할 수 있으므로 모든 주문의 정상 접수를 보장하지는 않습니다.

업데이트: 기존 서명키와 자동 업데이트 주소를 사용합니다. 실행 중인 미체결 주문이 있으면 자동 적용이 대기할 수 있습니다. 앱에서 업데이트 확인을 누르면 기존 중지·미체결 취소 확인 절차 후 설치됩니다. 재시작 후 주문 실행 여부는 사용자의 기존 설정을 따릅니다.

검증: 신규 49개 회귀 검증과 기존 Windows PowerShell 5.1 검증을 실행합니다. 테스트는 합성 데이터만 사용하며 실제 계좌 접근·주문은 수행하지 않습니다. 설치 여부는 앱 버전과 메인PC 진단 로그로 별도 확인해야 합니다.
