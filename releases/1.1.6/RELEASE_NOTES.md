# Avata 1.1.6 / 58.17.12

- 시트 표시값을 이전 성공 전송과 비교하여 바뀐 범위만 갱신합니다. 주문내역은 실제 사용 행과 지워야 할 이전 행까지만 전송합니다.
- 자산 요약은 바뀐 셀만, 자산 상세 표는 내용이 바뀔 때 전송합니다. 표 서식은 구조가 달라질 때 적용하며 날짜 범위 수식은 실제 마지막 행까지만 참조합니다.
- 자산 탭의 빈 행을 줄여도 내역이 늘면 필요한 만큼 250행 단위로 확장하고 기존 매수·매도 조건부 서식을 이어갑니다.
- 최초 실행·캐시 오류·전송 결과 불명·5분마다 전체 값 재검증을 수행합니다. 전송 전에 대기 표시를 저장하여 응답 유실 후 잔여 주문/자산 행도 복구합니다.
- 진단 로그에 전송 셀 수, 전송/생략 범위 수, 전체 갱신 여부를 추가했습니다. 캐시에는 계좌·주문 내용 대신 해시와 행 수만 저장합니다.
- 전략 입력 조회, 체결 확인, 매매일지 검증 및 실시간 진단 주기는 유지합니다. 기준표 지정가 주문, 거래 제한, 텔레그램 출퇴근 알림은 그대로 유지합니다.
- 프로젝트 구조·운영·검증 문서와 현재 전체 소스를 찾는 진입점을 정리합니다. `source/`는 변경 파일 발췌이며 완전한 소스·테스트는 Verification ZIP입니다.

합성 측정: 기존 표시 전송은 12,388셀이며 주문 3행만 변경된 사례에서는 36셀, 시각만 바뀐 사례에서는 1셀을 전송합니다. 실제 감소율은 당시 변경 내용에 따라 달라집니다. 모바일 로딩 시간은 실기기 측정 전입니다.

업데이트는 앱의 업데이트 버튼을 사용합니다. 기존 중지·미체결 확인 절차와 자동 시작 설정을 유지합니다. 외부에서 직접 수정한 표시값은 최장 5분 후 전체 값 갱신에서 복구합니다.

검증: Windows PowerShell 5.1 전체 792개 합성 검증과 공개 자동업데이트 서명·다운로드 검증을 통과해야 배포합니다. 실제 계좌·주문·텔레그램 전송은 시험에 사용하지 않습니다.
