Avata 58.17.3 — 실행 후 자동 시작 옵션·트레이 실행

**업데이트 후 처음부터 트레이에서 시작합니다.** Windows 오른쪽 아래 숨겨진 아이콘(∧)에서 아바타 아이콘을 두 번 누르거나, 우클릭 → 아바타 열기를 선택하세요.

- 실전 제어 탭에 ‘실행 후 준비되면 자동 시작’ 옵션을 추가했습니다. 기본값은 꺼짐입니다.
- 사용자가 현재 PC·계좌·종목에 대해 한 번 확인하고 켜면, 이후 실행·재시작·업데이트 후 준비가 완료될 때 자동으로 실주문을 승인합니다. 장중에는 기존 전략에 따라 실제 주문이 나갈 수 있습니다.
- 최신 계좌 대조 2회, 미체결·미확정 주문 확인, 정상 관리자 상태, 설치 검증 완료를 기다립니다. 기존 30분할 전략과 하루 새 매수 3차수 제한을 유지합니다.
- 정지 또는 일시정지를 누르면 자동 시작 설정도 꺼집니다. 창 종료·업데이트 중에는 해당 실행의 대기 중 자동 시작을 취소합니다.
- 실행마다 자동 시작 요청은 한 번만 보냅니다. 설정 변경·동의 취소·전략 변경·중지 요청은 주문 처리 직전에 다시 확인합니다. 실패 시 무한 자동 재승인하지 않습니다.
- 최소화하면 작업표시줄에서 사라지고 트레이에 남습니다. 창 열기는 트레이에서 직접 선택해야 합니다. 자동으로 창을 활성화하거나 알림 풍선을 띄우지 않습니다.
- 58.17.2의 날짜 전환, 예탁금이용료 대조, 매매 없는 날 자산내역 갱신 수정은 그대로 포함합니다.

검증: Windows PowerShell 5.1 가상 데이터·격리 환경 검사 205건. 실제 화면을 띄우지 않는 전체 프로그램 시작·상태 갱신·관리자 재시작 종료도 확인했습니다. 실계좌 주문은 시험하지 않았습니다. 실제 장중·자정 연속 운영은 별도 확인 대상입니다.

파일:

- avata-update.json: 고정 공개키로 검증하는 업데이트 정보.
- Avata_58.17.3_Verification.zip: 재현 가능한 소스·가상 데이터 검사 묶음. 설치 도구가 아닙니다.
- SHA256SUMS.txt: SHA-256.

기존 실주문 중 업데이트 보류 조건은 유지합니다. 이 릴리스가 자동 시작 동의를 새로 만들거나 기존 계좌의 옵션을 대신 켜지는 않습니다.
