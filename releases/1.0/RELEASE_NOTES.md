# Avata 공식 1.0

검증된 **58.17.4**를 공식 제품 버전 **1.0**으로 지정합니다.
프로그램에 표시되는 내부 빌드 번호는 **58.17.4**입니다.
기존 자동 업데이트와의 호환성을 위해 내부 버전과 서명된 파일을 그대로 유지합니다.

## 포함 기능

- 트레이에서 실행하고 최소화하면 트레이로 숨깁니다.
- 트레이에서 시작해도 계좌 조회가 정상적으로 시작됩니다.
- 사용자가 해당 PC·계좌·종목에서 선택한 경우, 준비 완료 후 실주문을 자동 승인합니다.
- 날짜 전환, 예탁금이용료 대조, 매매 없는 날 자산내역 갱신 수정을 포함합니다.
- 실주문 중 업데이트 보류 및 주문·계좌 대조 조건을 유지합니다.

## 기존 PC 업데이트

기존 Avata_kor 실행 도구를 정상 실행하면 기존 자동 업데이트 주소에서 같은 빌드를 받습니다.
실행 중인 프로그램이 있다면 안전한 종료가 완료된 뒤 다시 실행하세요.
실주문 중에는 업데이트가 보류될 수 있습니다.

새 빌드는 트레이에서 시작합니다. 오른쪽 아래 숨겨진 아이콘(∧)에서 아바타 아이콘을 두 번 눌러 창을 여세요.
계좌 조회 완료 후 프로그램 표시가 58.17.4인지 확인합니다.
이미 58.17.4가 적용된 PC에는 이번 공식 버전 지정으로 재설치나 재시작을 요구하지 않습니다.

자동 실주문 시작은 PC별 선택 사항이며 기본값은 꺼짐입니다.
동일 계좌를 사용하는 다른 PC에서 실주문을 실행 중이라면 이 PC는 조회 용도로 사용하세요.
업데이트 자체가 자동 실주문 시작 설정을 새로 켜지는 않습니다.

## 검증 및 배포

- Windows PowerShell 5.1 격리 환경 검사 209건을 통과한 58.17.4와 동일한 파일입니다.
- 공식 1.0 배포에서 네 개 첨부 파일의 SHA-256, 서명, 번들 파일 일치 여부를 다시 확인합니다.
- 배포 후 기존 58.17.0 업데이트 모듈로 공개 피드 다운로드 및 동일 버전 재확인 경로를 검사합니다.
- 실제 장중 주문과 자정 연속 운용 결과는 별도로 확인해야 합니다.
- 개인정보, 인증정보, 실제 계좌 원장·실행 로그 및 서명 개인키는 포함하지 않습니다.

서명된 피드의 패키지 주소는 기존 v58.17.4 릴리스 파일을 유지합니다.
최신 릴리스 v1.0에 첨부된 패키지 및 피드도 같은 바이트입니다.
