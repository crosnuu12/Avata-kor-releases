Avata 58.17.2

날짜가 바뀐 뒤 입력 갱신이 멈추는 문제, 예탁금이용료 때문에 현금 대조가 보류되는 문제, 매매 없는 날 자산내역 갱신이 실패하는 문제를 수정했습니다.

- 증권사 원본 거래내역의 예탁금이용료와 실제 세액을 검증해 순이자를 계산합니다. 주식 매매 실현손익에는 포함하지 않습니다.
- 기존 원장과 현금 기준을 보존합니다. 알 수 없는 입출금, 오래되거나 불완전한 근거, 미확정 주문은 계속 차단합니다.
- 실주문은 업데이트 후 자동으로 시작하지 않습니다.
- Windows PowerShell 5.1 가상 데이터 검사 181건을 통과한 패키지입니다.

파일:
- Avata_kor-58.17.2.zip: 자동 업데이트용 앱 번들. 소스 포함.
- avata-update.json: 기존 프로그램의 고정 공개키로 검증하는 서명된 업데이트 정보.
- Avata_58.17.2_Update_Kit.zip: 호스트 갱신 및 입력·현금 대조 복구를 위한 Windows 적용 도구. 압축 해제 후 Start_Update.cmd 실행.
- SHA256SUMS.txt: 배포 파일의 SHA-256.

기존 호스트는 실행 시 새 배포를 확인합니다. 실행 중에는 계좌 대조 및 주문 상태를 확인하며, 설정에 따라 업데이트 버튼 조작이 필요할 수 있습니다. 적용 도구는 호스트와 실행 중 자동 적용 설정도 갱신합니다. 앱 번들만으로 호스트가 교체되지는 않습니다.

실제 PC 적용과 장중·자정 운용은 별도 확인이 필요합니다. 인증정보, 개인 시트 주소, 실제 계좌 자료, 실행 로그, 서명 개인키는 포함하지 않습니다.
