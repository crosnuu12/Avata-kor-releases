# Avata 1.1.12 / 58.17.18

정상 조회 경로 `/trading/v1/orders/history`가 진단 아카이브 검증에서 거절되어 전송이 멈추는 문제를 수정합니다. 기존에 순번이 배정된 대기 로그도 큐를 초기화하지 않고 같은 순번으로 재전송합니다. 큐 상태를 읽을 수 없을 때는 대기 0건 대신 상태 미확인으로 표시합니다.

작업자에서 처리하지 못한 예외는 `worker-error.json`에 오류 종류·안전한 코드·실행 ID·발생 파일명과 행 번호를 남기고 진단 요약 및 아카이브로 전달합니다. 원문 예외 메시지, 전체 경로, 소스 코드, 계좌·주문 식별자와 인증정보는 수집하지 않습니다. 기록 저장 자체가 실패해도 기존 예외 및 REVIEW 중지는 유지합니다.

이번 버전은 WORKER_FAILED의 최초 원인을 해결했다고 주장하지 않습니다. 앞선 작업자 중단으로 체결 수신 기록이 오래되면 FEED_STATUS_MISSING 경보가 뒤따를 수 있습니다. 실시간 수집기의 갱신 시각만으로 자동매매 정상 여부를 판단하지 말고 runtime과 조회 원본의 시각을 함께 확인해야 합니다. 자동 실주문 승인·주문 재시도·자동 재시작 조건은 변경하지 않습니다.

합성 자료로 정상 API 경로, 잘못된 경로 차단, 저장된 큐의 재전송, 작업자 예외 기록과 정보 필터링을 검증합니다. Windows PowerShell 5.1 검증과 공개 상태는 STATUS.md를 확인하십시오. 공개 배포와 실제 PC 적용은 별도로 확인합니다.
