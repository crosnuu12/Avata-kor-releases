## 아바타 1.1.2 (내부 버전 58.17.8)

같은 계좌·종목·날짜·주문번호의 분할 체결을 매매일지 한 행으로 통합합니다. 수량은 합산하고 단가는 수량 가중평균으로 표시하며 체결금액은 정확한 합계를 보존합니다. 수동 기록은 유지하고 원래 체결 순서로 손익을 계산합니다. 텔레그램 시작 승인과 입력 갱신 진단 개선도 포함합니다.

**기존 설치 PC에서는 새 업데이트 키를 한 번 적용해야 합니다.** 이전 배포 개인키를 찾지 못해 소유자 요청으로 새 키를 발급했습니다. 기존 앱은 새 키 적용 전까지 이 업데이트의 서명을 거부합니다.

1. 아바타에서 실주문을 정지하고 프로그램을 완전히 종료합니다.
2. `Avata_Update_Key_Recovery_1.1.2.zip`을 내려받아 압축을 풉니다.
3. `Apply_New_Update_Key.cmd`를 실행하고 완료 문구를 확인합니다.
4. 기존 `Avata_kor`를 실행해 1.1.2 업데이트와 계좌 조회 상태를 확인합니다.

이 복구는 각 PC에서 한 번만 필요합니다. 이후 배포는 새 키로 계속 서명합니다. 개인키를 앱에 입력할 필요는 없습니다. 복구 도구에는 공개키만 있으며 계좌 인증정보, 매매 원장, 시트 설정과 주문 설정을 변경하거나 실주문을 시작하지 않습니다.

애플리케이션은 기존 Windows PowerShell 5.1 검사 532개를 통과한 동일 바이트입니다. 새 키 복구 검사는 별도 Windows 작업에서 실제 서명 검증, 두 기존 업데이트 프로그램의 키 교체, 파일 잠금, 실패 시 원복, 중복 실행과 개인 데이터 보존을 확인합니다. 실계좌/실주문 테스트는 하지 않았습니다. 이미 통합된 매매일지를 구버전으로 되돌리는 경우 원래 체결 원장을 기준으로 복구해야 합니다.

`Avata_kor-58.17.8.zip`은 자동 업데이트 전용이며 직접 덮어쓰는 설치 파일이 아닙니다. 기존 설치 도구에는 이전 키가 들어 있으므로 재설치 대신 위 복구 도구를 사용하세요.
